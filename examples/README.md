# Supported examples

Only the current strict mission contracts are retained:

- `mission-security-profile.example.yaml`: TC-only provisioning input.
- `mission-security-profile.downlink.example.yaml`: TC + 8-slot downlink KEK provisioning input (requires `-tags downlink`).
- `downlink-hardware-simulator`: runnable RAW downlink producer for ground integration tests (requires `-tags downlink`).

All values are public test material and must never be used in flight.
